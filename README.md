# مصحف المدينة - رواية حفص — الإصدار الحديث v2

المصحف الرقمي الحديث برواية حفص عن عاصم، تجربة قراءة سلسة ومتوافقة مع كافة الأجهزة.

## البنية الهيكلية للمشروع
- `index.html` : القشرة الهيكلية الخفيفة بدون تبعيات خارجية ثقيلة
- `manifest.webmanifest` : تهيئة التثبيت كتطبيق مستقل PWA
- `sw.js` : خدمة الكاش الذكية ثلاثية الطبقات ودعم العمل بلا إنترنت
- `src/app.js` : المنطق البرمجي والتنقل بالسناب والفهرس
- `src/arabic.js` : محرك تطبيع النصوص والبحث الموحد
- `src/data.js` : إدارة وجلب بيانات الكتاب
- `src/audio.js` : مشغل الصوتيات
- `data/book.json` : بيانات الفهرس وروابط الصفحات
- `icons/icon.svg` : أيقونة متجهة عالية الدقة

## التشغيل محلياً
```bash
# عبر بايثون
python -m http.server 8080

# أو عبر Node
npx serve .
```
ثم افتح: `http://localhost:8080`
